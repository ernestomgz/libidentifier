# Generated validation output

This directory holds ignored JUnit, JSON and local diagnostic output. Only this
guide is tracked. Selected dated evidence lives in
[development validation](../docs/development/validation/stage2-validation.md).
Reusable schema-2 profiles belong in `.local/profiles/`, native tools in `.tools/`,
reference source caches in `.local/reference-artifacts/` and optional advisory
snapshots in `.local/advisory-db/`. Never publish these local resources as an
official release without the [release checklist](../docs/development/release-readiness.md).
